# HP記事のSEO・AIO対策

SEED VOCAL SCHOOL のホームページ（http://seedvocalschool.com/ 、WordPress）に載せる記事を、検索（SEO）と AI の回答（AIO）の両方で拾われ、読んだ人が「しっかりした教室だ」と感じる形で作るための領域。

対応する Addness のゴール：「ホームページの記事でSEO・AIO対策の土台を作る」 https://www.addness.com/goals/00a8b63f-f658-4a28-8454-9a22991b4555
進み具合・決めたことは、このゴールの本文に書く。

## 中にある物

| ファイル | 何か | いつ使うか |
|---|---|---|
| 記事テンプレ.md | 1本の記事の穴埋めの型。WordPress の入力欄の表、記事の10の節（結論→導入→著者→本文→SEEDの基準→よくある質問→動画→公式LINE→参考→関連記事）、公開前チェック | 記事を1本書くたび |
| 構造化データの方針.md | Article・Person・Organization・FAQPage を出すか・どう出すかの方針と、SEED の値を入れた JSON-LD の型。確かめた事実と出典つき | サイトの設定を触る時、ExUnit を更新した時 |

## 使う時のコツ

- 記事テンプレはコピーしてから埋める。元のファイルは書き換えない。
- 1本ずつの下書きを残すなら、このフォルダに `記事/スラッグ.md`（例：`記事/husler-method.md`）で置く。
- 下書きは AI、監修と公開は山口はるき。WordPress にはまず「下書き」で入れる。
- 構造化データの方針の【未確認】は、管理画面やリッチリザルト テストで確かめたら、事実に書き換える。
